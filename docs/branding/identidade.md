# Identidade visual inicial

**Nome:** nassauTickets. **Contexto:** laboratório de análises clínicas; uma interface simples para emissão, chamada e acompanhamento.

| Elemento | Definição |
| --- | --- |
| Cor principal | Verde escuro `#103d37` |
| Destaque | Verde claro `#d7eb94` |
| Fundo | Neutro claro `#f5f6f2` |
| Texto | Verde escuro `#183d37` |
| Tipografia | Fontes locais: Inter se disponível, Segoe UI, Arial, sans-serif |
| Marca inicial | “n.” em bloco arredondado e nome textual |

O protótipo não depende de imagens ou fontes externas. Cor nunca é a única indicação: tipos possuem códigos SP/SE/SG e rótulos textuais. Os botões têm foco visível e a interface adapta os cartões para uma coluna no celular. A identidade é proposta do projeto acadêmico, sem alegação de marca oficial da instituição.
